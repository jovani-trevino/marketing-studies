## 1. Pregunta y aportación

- [ ] El artículo responde una pregunta concreta y define a quién puede ayudar.
- [ ] El resumen explica qué aprenderá el lector y hasta dónde llega el análisis.
- [ ] El título describe el contenido sin prometer resultados que el texto no demuestra.
- [ ] La aportación propia está identificada: análisis, experiencia documentada, comparación, método o ejemplo.

## 2. Fuentes y atribución

- [ ] Las cifras, citas y afirmaciones verificables tienen una fuente identificable junto al pasaje correspondiente.
- [ ] Abrí las fuentes y comprobé que respaldan la afirmación exacta, su periodo y su contexto.
- [ ] Priorizo investigaciones originales, documentación oficial y datos de primera mano cuando están disponibles.
- [ ] Cada referencia conserva autor o institución, título, fecha y URL o DOI real. No añadí identificadores ni bibliografía que no pude verificar.
- [ ] Distingo lo que documenta la fuente de mi interpretación y de una recomendación personal.
- [ ] Las citas textuales son precisas y breves; las imágenes, datos y materiales reutilizados tienen el permiso o la atribución que corresponde.

## 3. Método, datos y límites

- [ ] Explico de dónde salen los datos y cómo se seleccionaron, limpiaron o compararon.
- [ ] Las métricas indican población, periodo, unidad y, si son tasas, numerador y denominador.
- [ ] Los ejemplos simulados están marcados como ilustrativos y se distinguen de observaciones reales.
- [ ] Los cálculos pueden repetirse con la información aportada; revisé totales, porcentajes, fechas y unidades.
- [ ] Describo límites, datos faltantes y explicaciones alternativas. La conclusión respeta lo que el método permite afirmar.
- [ ] Si menciono revisión externa, revisión por pares, una certificación o un resultado de cliente, puedo acreditar el proceso o dato y tengo autorización para publicarlo.

## 4. Edición y formatos

- [ ] La introducción presenta el problema y el cierre responde la pregunta inicial con pasos concretos cuando son pertinentes.
- [ ] Defino siglas y términos técnicos al usarlos por primera vez; elimino repeticiones y frases ambiguas.
- [ ] Código, fórmulas, tablas y listas conservan signos, saltos de línea y unidades después de guardarlos en el editor.
- [ ] Las versiones ES/EN conservan el sentido, los enlaces, las cifras y las limitaciones del mismo artículo.

## 5. Lectura accesible

- [ ] Los encabezados describen cada sección y utilizan una jerarquía coherente.
- [ ] Los enlaces anuncian su destino; las descargas indican el tipo de archivo.
- [ ] Las imágenes informativas tienen texto alternativo útil; las decorativas no añaden ruido a la lectura.
- [ ] El contenido audiovisual incluye subtítulos o transcripción según corresponda.
- [ ] Revisé la vista móvil, el aumento de texto, el contraste y la navegación por teclado. Las animaciones permiten leer y usar los controles con comodidad.

Consulta las orientaciones de [W3C WAI para escribir contenido accesible](https://www.w3.org/WAI/tips/writing/) al realizar estas comprobaciones.

## 6. Publicación y mantenimiento

- [ ] La autoría y la fecha de publicación son correctas. La fecha de actualización corresponde a una revisión real.
- [ ] La portada, el resumen, la categoría y la descripción para buscadores representan el artículo publicado.
- [ ] Probé enlaces internos y externos, selector de idioma y archivos descargables.
- [ ] Revisé que capturas, ejemplos y archivos no expongan información privada ni credenciales.
- [ ] Registré qué cambios hice, qué queda pendiente y qué afirmaciones necesitarán otra revisión.

La guía de [Google Search Central sobre contenido útil y fiable](https://developers.google.com/search/docs/fundamentals/creating-helpful-content) ofrece preguntas adicionales para evaluar utilidad, claridad de autoría y aportación original.
